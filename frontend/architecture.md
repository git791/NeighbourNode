# NeighborNode - Core Screen Architecture & Wireframe Breakdown (8 Views)

1. **Homepage / Role Navigation Hub**
   - **Tagline:** "no food waste and no empty stomachs"
   - **Interactive Navigation Buttons:** Dashboard, Fridge Host, Delivery, Donate, and Receive Aid.
   - **Header Element:** User profile quick-access link.

2. **Register / Login Portal**
   - **Input Fields:** Username, Email, Phone, and Password.
   - **Action Trigger:** Authenticate button.

3. **My Account / Profile View**
   - **User Details:** Avatar, Name, Role (e.g., Fridge Host), Neighborhood/Hub location, and Account Status.
   - **Contact Data:** Email and Phone number display.
   - **Action Controls:** "Make Changes" button and "Logout" trigger.

4. **Donor Page (Log Your Donation)**
   - **Donation Form Fields:** Business/Individual name, Pick Up Location, Food Category, Quantity, Expiry Time, and Preferred Pick Up Time.
   - **Submission Action:** "Submit to Agent Network" button.
   - **Sidebar Component:** Community Leaderboard ranking.

5. **Aid Receiver Page (Find Food / Get Updates)**
   - **Public Notice:** 24/7 community fridge availability statement ("Take what need, leave the rest").
   - **SMS Restock Alerts Form:** Phone number input field, neighborhood selection dropdown, and subscription trigger.

6. **Coordinator Dashboard**
   - **Navigation Sidebar:** Overview, Fridges, Approvals, Reports, and Settings.
   - **Metric Cards:** Total fridges (24), Stocked (15), Empty (5), and Low (4).
   - **Visual Components:** Community Map with color-coded status pins (Red = Empty, Yellow = Low, Green = Stocked), Live Activity Feed, and Approval Queue for new donation offers.

7. **Delivery Person Page (Delivery Runner Active Route)**
   - **Mission Control:** Assigned delivery missions, featuring pickup details, item quantities, and drop-off specifications.
   - **Action Controls:** "Mark as Delivered" and "Re-assign this Delivery" buttons.
   - **Routing Visual:** Integrated delivery route map view.

8. **Fridge Host Page**
   - **Hub Header:** Community Fridge (number and location).
   - **Status Indicators:** Interactive capacity fill-meter (how full) and current temperature monitor.
   - **Emergency Control:** "TRIGGER EMPTY ALERT" button.
   - **Activity Log:** Recent fridge activity tracker (timestamps for items added or taken out).
